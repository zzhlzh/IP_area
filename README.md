# 地区对齐检测 · IP / 时区 / 账号

> 一个常驻浏览器的小插件，随时帮你对照三件事对不对得上：
> **IP 出口地**（网站眼里你从哪上网）、**设备时区**（电脑告诉网站的本地时间）、**常驻地 + 各账号的地区设置**。
> 对不上时，它提前用人话提醒你，而不是等安全警告邮件来了再猜「是不是我本人」。

![version](https://img.shields.io/badge/version-1.1.0-blue) ![Manifest V3](https://img.shields.io/badge/Manifest-V3-green) ![license](https://img.shields.io/badge/license-MIT-lightgrey)

## 为什么做这个

很多人都遇到过这种莫名其妙的时刻：

- 人在成都，手机/宽带出口却走香港，Meta/Google 的安全提醒里登录地点就变成了「香港附近」，每次都要心惊一下：这是我吗？
- 账号地区按另一套规则判定，人在本地、网络也在本地，某些按地区开放的功能还是用不了。
- 三套信息（实际所在地、IP 出口、账号地区）平时互相对不上，本人却完全看不见，直到敏感操作触发风控才知道。

这个插件做的事很简单：**把这三套信息摆到同一个面板上对齐给你看**，并在你做登录、改设置、用地区限定功能之前先提醒一句。

## 功能

- 🌏 **三方对照**：IP 出口地、设备时区、常驻地、Google / Meta / Muse / Apple 各账号地区，逐项标「与 IP 一致 / 不一致」
- 🚦 **风险分级**：✅ 都对得上 / ⚠️ 有小冲突 / 🚨 关键项对不上（附人话原因，逐条说明哪两项在打架）
- ⏱ **定时检测**：默认每 30 分钟自动查一次（间隔可改），工具栏角标同步状态：`✓` 对齐、`!` 有冲突、`!!` 严重冲突
- 🔔 **变严重才打扰**：冲突从无到有、或等级上升时才弹系统通知，安静时不刷存在感
- 🔀 **多源兜底 + 超时**：IP 查询依次尝试 ipapi.co → ipwho.is → api.country.is，单个源 6 秒超时自动切换；全部失败时老实显示「这次没查出来」，绝不编一个结果
- ⚡ **打开不等待**：面板先显示上次检测结果，再后台刷新到最新
- 🔒 **不碰账号**：不登录、不读取任何平台账号；账号地区由你按账户中心显示填写一次即可。详见 [PRIVACY.md](PRIVACY.md)

## 安装

支持 **Chrome / Edge**（以及其他 Chromium 内核浏览器），Manifest V3，无需打包、无需商店审核，用「加载未打包的扩展」方式安装。

### 方式一：下载本仓库

1. 点本页面右上角绿色的 **Code → Download ZIP**，下载后解压到一个固定位置，例如 `D:\IP_area`。
   - ⚠️ 确认解压后 **`manifest.json` 就在该文件夹根目录**（能看到 `D:\IP_area\manifest.json`）。如果套了两层文件夹，把内层移出来一层。
   - 这个文件夹以后不要移动或删除，浏览器每次启动都要从这里加载扩展；想更新版本时，用新文件覆盖后在扩展页点刷新即可。
2. 打开扩展管理页：
   - Edge：地址栏输入 `edge://extensions`
   - Chrome：地址栏输入 `chrome://extensions`
3. 打开页面上的 **「开发人员模式 / Developer mode」** 开关。
4. 点 **「加载解压缩的扩展 / Load unpacked」**，选择刚才的文件夹（如 `D:\IP_area`）。
5. （推荐）点工具栏的拼图图标 🧩，把「地区对齐检测」固定到工具栏。

### 方式二：git clone

```bash
git clone https://github.com/zzhlzh/IP_area.git
```

然后从上面第 2 步开始，选克隆下来的文件夹即可。

### 常见安装错误

| 报错 | 原因与解法 |
|---|---|
| `Default locale was specified, but _locales subtree is missing` | v1.0.0 的已知问题（声明了语言却没带语言文件夹），更新到 v1.0.1 以上即修复 |
| 提示找不到 `manifest.json` / 清单文件缺失 | 选错了文件夹层级：加载时要选**直接包含 manifest.json 的那一层**文件夹 |
| 加载成功但图标是灰色默认图 | 正常现象：本仓库不带二进制图标文件。想换自定义图标见 [icons/README.md](icons/README.md) |

## 使用方法

### 第一次：先设置（只做一次）

点扩展图标 → 面板下方 **「⚙ 设置常驻地 / 账号地区」**：

| 设置项 | 怎么填 |
|---|---|
| 常驻地代码 | 你长期居住地的两位国家/地区代码，如中国 `CN`、香港 `HK`、美国 `US`、日本 `JP`、新加坡 `SG` |
| 常驻地备注 | 显示用的地名，如「成都 · 天府新区」，随便写 |
| 各账号地区 | 按每个平台**账户中心里显示的实际地区**填同样的两位代码。查法：Google 在 myaccount.google.com 的个人信息里；Meta 在「账户中心 → 个人详情」；Apple 在 Apple ID 网站的「国家/地区」；Muse/Meta 系在账户设置里。拿不准就先和常驻地填一样，之后收到安全提醒时再对照修正 |
| 检测间隔 | 默认 30 分钟，最少 15 分钟 |
| 通知开关 | 建议开：冲突变严重时弹系统通知 |

填错格式（比如写了三个字母）保存时会有提示，改对再存。点「保存」后会自动用新设置重新检测一次。

### 日常使用

- **平时不用打开它**：它在后台定时检测，工具栏角标就是状态。看到 `!!` 红色角标，先点开看一眼再做敏感操作。
- **做这些事之前建议瞄一眼面板**：登录重要账号、修改账号地区/密码/双重验证、使用按地区开放的功能、连接不熟悉的网络（公司网、酒店 Wi-Fi、代理/VPN 开关前后）。
- **面板怎么看**：
  - 顶部结论卡：✅ 放心 / ⚠️ 小冲突 / 🚨 先别做敏感操作，下面一句话说清原因；
  - 中间四行事实：常驻地、IP 出口（国家+城市+IP）、设备时区、浏览器语言；
  - 账号对照表：每个账号标「与 IP 一致 / 不一致」；
  - 「提醒」列表：逐条说明哪两项对不上、可能带来什么后果。
- **手动重查**：点面板右上角「↻ 重新检测」（换了网络、开关了代理之后用）。
- **显示红色怎么办**：这只是风险提示，插件不会、也不应该替你修改 IP 或账号地区。你可以：换回常用网络后重新检测确认；或者照常操作，但之后收到安全提醒邮件时，你已经知道这次大概率是自己触发的。如果 IP 出口长期和常驻地不一致（比如网络运营商出口在外地），重点核对一遍各账号地区填写是否与账户中心一致。

## 工作原理（简版）

- IP 出口：向公开查询服务请求当前出口 IP 的归属地（国家、城市、运营商、该 IP 的时区），三源兜底、带超时。
- 设备侧：用浏览器自带的 `Intl` 接口读设备时区，用内置映射表推断时区对应地区；读浏览器语言作为辅助参考。
- 对齐判断（`lib/regions.js` 的 `evaluateAlignment`）：逐项比对 IP↔常驻地、设备时区↔常驻地、IP 时区↔设备时区、IP↔每个账号地区，按冲突严重程度合成等级与人话文案。纯函数，有自测覆盖。
- 后台（`background.js`）：用 `chrome.alarms` 定时跑同一套判断，更新角标，等级变严重时发通知。

## 隐私

检测全部在本机浏览器内完成；除了向 IP 查询服务发出的常规查询请求（对方会看到你的出口 IP，和你打开任何网站时一样），不上传任何数据，不碰任何账号。完整说明见 [PRIVACY.md](PRIVACY.md)。

## 开发与测试

```bash

node --check background.js && node --check popup.js && node --check options.js && node --check lib/regions.js
```

改完代码后在扩展管理页点该扩展的刷新按钮即可生效，无需重新加载文件夹。

## 文件结构

```
IP_area/
├─ manifest.json        扩展清单（Manifest V3）
├─ popup.html/css/js    点开图标看到的状态面板（先显示缓存结果，再后台刷新）
├─ options.html/js      设置页：常驻地、账号地区（带格式校验）、检测间隔、通知开关
├─ background.js        定时检测、角标、通知（通知图标为内嵌 data URL）
├─ lib/regions.js       地区表、时区→国家映射、对齐判断逻辑、IP 多源查询（含超时）
├─ icons/               可选的自定义图标生成脚本与说明
├─ tests/selftest.js    核心逻辑自测
├─ PRIVACY.md           隐私说明
└─ CHANGELOG.md         更新记录
```
